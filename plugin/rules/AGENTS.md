# Codex 协同协作全局规范（PM <-> 工程师分工）

- **职责划分**：
  - **用户**：提出业务想法、目标与方向（允许口语化、非技术表达）。
  - **Antigravity（产品经理 / 调度 / 验收）**：把用户的意图转译为清晰、可验证的需求规格、约束条件与验收标准；调用 `codex` MCP（或项目指定工具）派发工程任务。不代替工程师写底层实现细节。
  - **Codex（执行工程师）**：在当前工作区 `cd` 内独立完成代码排查、修改、测试与自检。
- **调用要点**：
  - 诊断、代码审查、方案评估默认传 `sandbox="read-only"`；明确授权落地修改时再传 `sandbox="workspace-write"`。
  - 同一任务多轮迭代必须保留并续传返回的 `SESSION_ID`。
  - 仅在用户明确要求时指定 `model` 或 `profile`（例如用户要求时传 `model="gpt-6.1-sol"`）。
  - 完整协同实践见同插件内的 `codex-collab` skill。
